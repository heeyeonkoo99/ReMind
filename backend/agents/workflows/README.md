# Loop 3: Workflows

**Owner:** TBD

The intent router (⑨) picks a workflow for an activated goal or a user question.

## Travel
All saves under a goal → extract places → dedupe → check operating status + location
→ group by area → rank by profile (budget, diet) → area-based shortlist
→ attach source save + video tip to every item → flag closed places

## Cooking
All recipes under a goal → extract ingredients + steps → apply profile (restrictions, skill, time)
→ pick the easiest dish for tonight → list missing ingredients
→ attach "jump to 1:15 for the key step"

Every output item must link back to the save it came from.
