### 4. Data sources: Instagram Graph API, TikTok API

Hazel's proposal: use the [Instagram Graph API `ig-user/media`](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media) and [TikTok for Developers](https://developers.tiktok.com/) for video data from both platforms.

After checking the docs: **neither API returns the videos a user has saved.** ReMind's input is saves, so we need to be clear about what each API is for.

| API | What it returns | Limits | Use in ReMind |
|---|---|---|---|
| IG Graph API `/<IG_USER_ID>/media` | Media the logged-in account **posted itself** (latest 10K, `since`/`until` pagination) | Needs a User access token and `instagram_basic` plus `pages_read_engagement` or `pages_show_list`. Not the saved list. `media_url` can be missing for videos with copyrighted audio. | Post demo videos to our test accounts and pull them in |
| TikTok Display API (`/v2/video/list/`, `/v2/video/query/`) | Metadata for the logged-in user's **public videos** | `video.list` scope. No access to likes or favorites. | Same as above |
| TikTok Data Portability API | User data export (Activity, etc.) | Returns data **only for EEA and UK users**. Review takes 3–4 weeks. Docs don't confirm whether favorites are included. | Not practical for us |

Summary:

- We get a user's **saves** the way the plan says: (1) paste a link, (2) upload the official "Download My Data" export.
- We use the two APIs for **video content and metadata**: filling in the title, caption, and thumbnail when someone pastes a link.
- Some permissions need platform review (Meta App Review, TikTok app review), which takes time. Until then, check whether yt-dlp metadata and oEmbed can fill the gap.

#### 4.1 How we actually get saved TikTok/IG videos (added after the meeting)

There is **no way to auto-sync a user's saved list today**: neither TikTok nor IG has an API for it. We have two paths, and both feed the same pipeline:

```text
 ① Paste a link (real time, one save at a time)  ┐
                                                  ├─→ list of video URLs → pipeline (download → ASR + key frames → Nuggets) → Agent
 ② Upload the data export (history, many at once) ┘
```

**① Paste a link: how every new save comes in**

User flow:
1. In TikTok or IG, tap **Share → Copy link** on the video.
2. Open ReMind, paste the link, tap Save.

Upgrade: an iOS Shortcut or Telegram bot that shows up in the system Share sheet, so saving is just "Share → ReMind" with no copy/paste. The backend handles it exactly like a pasted link.

What the backend does with the link:

| Step | Tool | Output |
|---|---|---|
| Fetch metadata | **yt-dlp** (open source; supports TikTok, IG, YouTube), or TikTok's public oEmbed endpoint (no login) | Title, description, hashtags, author, duration, thumbnail |
| Download video | yt-dlp | mp4 file |
| Understand content | ASR (speech to text) + a few key frames sent to a VLM | What the video says and shows → Nuggets |

Limits:
- **Public videos only.** Videos from private accounts are out of reach.
- IG sometimes requires login to download. In that case we may only get metadata, or need another workaround. **Test this first thing in M2.**

**② Upload the data export: bring in past saves in one go**

Both platforms have an official "Download your data" feature, which they provide to users by law, so this is fully within the rules.

User flow:
- **TikTok:** Settings → Account → Download your data → choose JSON → wait → download the zip
- **Instagram:** Your activity → Download your information → choose JSON → wait → download the zip (some guides say it can take up to 14 days, and the link expires after a few days)
- Upload the zip to ReMind.

What the backend does: unzip, find the JSON file with the saved list, read the **links and save timestamps**, then send each link into the ① pipeline.

Limits:
- The export has **only links and timestamps, no videos.** We still download videos by link with yt-dlp.
- An export can hold hundreds of saves, so we can't deeply process all of them. First pull metadata only for a rough classification, then download and analyze only the relevant ones.
- ⚠️ **Not yet confirmed that the export includes saved videos.** As far as we know, the IG export has a saved-posts file and TikTok's Activity data has a favorite-videos list, but we couldn't find official documentation, and the exact file names and formats are unverified.

**Why not other approaches**

| Approach | Why not |
|---|---|
| Official APIs | No access to saves, only the user's own posts (see the table above) |
| Log in with the user's account and scrape the saved page | Breaks platform terms, risks getting the user's account banned, and scrapers break easily |
| Browser extension that scrapes saves | Some exist, but same risks as above. We won't do it |

**Next steps**
1. **Both of us request TikTok and IG data exports today.** Opening our own exports is the most reliable way to check whether the saved list is there and what format it uses. If it isn't, path ② needs a new plan.
2. **During development we don't need either path yet.** Collect ~20 public video links by hand and use them as test data. The ① pipeline is M2 work; ② is M5 work.

Sources: [TikTok export guide](https://takeoutday.org/guides/how-to-export-tiktok-data) · [Instagram export guide](https://takeoutday.org/guides/how-to-export-instagram-data) · [What's in the Instagram data file](https://redact.dev/blog/instagram-data-file-download) · [How to export Instagram data](https://deciphertools.com/blog/how-to-export-instagram-data/)
