# Meeting notes

We keep notes from every meeting here. If a decision is recorded here, this is the source of truth.

## How to write them

- File name: `YYYY-MM-DD-topic.md` (e.g. `2026-10-20-kickoff.md`)
- Copy [`_template.md`](_template.md) to start.
- On the day of the meeting, open a PR from a `docs/meetings-<date>` branch. Merge once the other person has checked it.
- Always fill in **Decisions** and **Action items**, and give every action item an owner.
- If a decision affects CLAUDE.md or a README (stack, rules, owners), update them in the same PR.
- Review the previous meeting's action items at the top of the next notes.
